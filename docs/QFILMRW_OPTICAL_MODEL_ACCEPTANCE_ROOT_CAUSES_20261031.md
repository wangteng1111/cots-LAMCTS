# QfilmRW 完整光学模型验收未通过：原因审计

日期：2026-10-31。执行代码：785bd687cf1117adbc68312ce8ccbb3ff0479c96；原生结果：9bccfe80a40c2d81c5451fe46b781c92e2134008。本文只分析既有结果并新增独立诊断脚本，没有更新工作站求解器或重新提交计算批次。

## 一、0 组完整验收首先反映验证流程尚未完成

`evaluator/qfilmrw/solver.py:31` 初始化 model_scope_validated=False，当前没有基于独立模型验证记录将其置真的代码路径。收集器 full_condition_accepted 要求 CPU/GPU 数值收敛、全部实际网格算术一致和两端 model_scope_validated 同时成立，因此本实现无论数值结果多好，完整验收计数都会保持 0。

`api.py:33–34` 还固定返回 J_task=None、training_eligible=False、model_scope_validated=False；assemble_score 的调用没有提供 geometric_q 和 area_weights。因此最终 J 的完整组装也未形成可执行闭环。上一轮“完整验收 0”的统计不能解释为一套已经完成的独立物理验收证明 231 组结果全错。QfilmRW 0.1 目前是局部傅里叶数值原型，完整模型适用性验证和任务评分集成仍有实现缺口。

模型适用性验证、数值收敛、真实器材经验标定应保持三个维度。经过独立验证的模拟 J 可以训练该模拟器的代理模型；不必为了这个目标先完成全部实物标定。预测实物性能则需要对应的经验验证。

## 二、主误差不能只从 REFERENCE_REQUIRED 标签判断

CPU 的 231 工况分为：67 数值收敛、118 参考检查未通过、30 源采样未收敛、14 瞄准/遮挡未分辨、2 后续门限失败。118 个参考失败中有 81 个初始瞳面检查也未通过，只有 37 个已通过该瞳面比较。标签优先返回参考失败，掩盖了这些重叠失败。

更重要的是：参考探针在 angular_grid=1024 时检查，未通过便结束，尚未执行后续 angular_grid=2048 的独立加密。参考差同时含源求积、重构和传播近似的影响，不能直接归因为局部傅里叶传播失效。

## 三、新增 A/B/C 同源算子分解

A：同一有限光线束、同一边界场上的精确距离标量 RS1；B：原始非均匀源节点直接执行局部角频域求和，恢复与当前参考探针相同的公共二次相位；C：对重建角网格直接做 MFT，故将 CZT 本身的舍入误差从这一步比较中排除。

诊断在本地 CPU、Torch 2.15.0+cpu 执行，原工作站为 Torch 2.14.0+cu130。使用原生终态的物理中心、波长、1024 瞳面、1024 角网格和探针位置。所有百分比都是有限探针向量的相对 L2 差，不是全图 PSF 或 MTF 误差界。

轴上 C-A 复场差 0.03265749970808，与工作站原生 0.03265749970875 几乎一致，说明已复现该失败。边缘重放为 0.01004940，原工作站 CPU 为 0.01003225；差异伴随被剔除查询数变化，符合当前拓扑分类对实现/舍入敏感的记录。

在这两个代表工况及其固定有限源求积下，主要不一致发生在重建/求积转换阶段；传播近似的探针强度差很小。这不能外推成全部 118 组都只有重构问题，也不能据此认定有限源 RS1 已是连续物理真值。下一步仍须独立检查 A 的源求积收敛。误差向量可相互抵消，表中两项复场差不能相加成 100% 归因。

## 四、重构与设备不一致的具体机制

当前流程包括仿射初始化、16 次受限 Newton、双线性采样和 0.5 mask 判定；部分失败点再用 Delaunay 三角形回退。仅接受来自相邻 u/v 源单元的三角形，其他点以零场处理。被排除面积有记录，但没有对相应遗漏复振幅或强度建立误差界。

这可能产生未被正确表示的孔径区域、复振幅求积偏差或相位插值偏差。相邻瞳面结果的收敛只能说明这些实现之间趋于稳定，并不自动证明该重构的系统偏差已经消失。A/B/C 分解已经证明该阶段在两个样本中显著改变了场结果，但尚未单独量化裁剪、Jacobian 近似、插值和源求积的各自贡献。

23 组全部实际网格算术一致性失败集中在 EF35 h=1、EF40 h=1、RF16 h=.5 等工况。原生 CPU/GPU 有效光线数相同，但 EF35/h1/550 nm 的 N=1024 unsupported 查询为 12152 vs 12275；RF16/h.5/630 nm 联合网格为 25356 vs 25327。细小浮点差异被离散边界判断放大，是有直接证据支持的重要候选机制；尚需固定同一几何/拓扑计划重放来排除其他分量。

## 五、传播近似仍有适用域，但不能先把所有失败都归因于它

精确距离满足 r_j(delta)=r0_j+s_j·delta+1/2 delta^T H_j delta+O(|delta|^3/r0_j^2)。当前保留 r0_j 和一阶项，使用公共 H_ref 恢复二次相位，并将 RS1 振幅因子固定在参考点。遗漏项包括源相关的二阶曲率、三阶以上项、振幅因子在像面上的变化。

当同源 B-A 本身超出目标，才需要改变物理传播分支，例如分块参考相位/更高阶展开、适用的补偿平面传播或独立直接参考。Ansys 官方也明确区分 FFT 与 Huygens 的适用条件；其产品的具体判据不能未经推导直接套给当前补偿后的算法。

## 六、验收指标和最终观测量尚未完全对齐

现有参考门限是约 21–22 个点的复振幅 L2 相对差 <=0.005。像面复振幅 E 乘任意单位模空间相位后，强度 |E|^2 不变，所以像面复场差不等于 PSF 强度差；复场门限也不是 MTF 误差门限。复 OTF 的相位则关系到物理像面位置和色差，仍需要保留。

对同一窗口、同一物理坐标、同一归一化下的 PSF，OTF 差可由归一化强度差的 L1 范数控制。稀疏探针不能给这个全窗口范数或全局 MTF 精度提供保证。应增加同一观测量的参考比较，保持复场检查作为诊断，并以经过验证的误差预算连接到最终 J。

## 七、0.25 um 像面采样不是当前已观察失败的主要位置

进入后续完整加密流程的 69 组，angular_grid、support、pitch、joint 四类比较均全部通过。剩余两个后续失败（RF24/h.5/430 nm、RF50/h0/510 nm）是联合加密后的参考复场差分别为 0.00509946 和 0.00508324，略高于 0.005，而不是像面间距、窗口或联合 OTF 比较失败。

这个结论只适用于已经走到这些检查的 69 组，不证明其他 162 组的像面采样已经验证。继续减小像面点距并不会自行补足源节点覆盖、修正重构或完成模型验证。

## 八、样本与测试视场也需校核

RF16 原始固定源文件明确注明该专利实例不能覆盖全画幅，r_sensor=18.2 mm；本轮统一使用 36x24 mm，半对角线为 21.6333 mm。其全幅边缘测试存在适用域不匹配，不能直接把零透过归因于求解器精度，也不能将它当作量产 Canon RF16 的实测覆盖结论。该注记并未独立证明本次零透过的唯一原因，仍须分表面失败日志和独立光线瞄准验证。RF24 的另外七个零透过工况仍未得到该来源证据解释。

当前源仍是商品命名的公开专利处方；材料、物方状态、设计视场和实际制造结构均需明确对齐。

## 九、物理边界场与任务评分的缺口

当前 source power 按均匀 stop-plane scalar z-flux 定义，无 Fresnel、镀膜或偏振输运。RS1 与局部模型共享这套边界场，彼此接近只能验证该声明边界条件下的传播，不能独立验证瞄准、OPL、Jacobian、照明和实际入口瞳功率分布。

可以先验收一个明确的无损标量、指定照明模型，不必一次加入全部电磁细节；但其适用范围与独立参考必须一致。当前有限窗口目标也可以独立验收；只有声称全平面 OTF 时，才额外需要窗口外能量或等价性证据。最后还要补齐几何/照度/色差量、共同像面光谱合成、区域权重和最终 J 的组装。

## 建议优先次序

1. 对测试处方、物方条件和有效视场做前置核对，区分域内精度测试、域外拒绝与瞄准失败。
2. 优先修复或绕开当前有损角域重构；冻结原始源节点和权重，回放 23 个设备差异工况。
3. 验证直接作用于 B 的非均匀傅里叶求和快路径。B 已是 sum_j c_j exp(-2 pi i q_j·x)；规则像面经尺度/原点相位处理可用 type-1 NUFFT，稀疏非规则点可用 type-3。FINUFFT/cuFINUFFT 支持这些数学任务。它减少当前重构路径的损失，但仍须独立验证源求积收敛、CPU/GPU 误差和适用域；不能把未化为傅里叶和的完整精确 RS1 内核直接交给 NUFFT。
4. 在更广的代表工况执行 A/B/C 分解；仅对 B-A 超标的情形开发更一般的传播算子。
5. 以对齐 PSF/复 OTF/J 观测量的独立参考验证模型适用范围，再补齐最终评分输出和证据驱动的模型验收状态。
