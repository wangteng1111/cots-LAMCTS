## 4. RF24 NaN 保存故障已修复并复验

原 RF24 GPU 任务完成中心 7 张 PSF，记录其他 14 个无效组合后，因为无效基线指标中的 NaN 无法写入严格 JSON 而失败。问题位于报告保存，不是这 7 张 PSF 尚未计算。

修复后：

- 无效的非有限指标以明确的 `null` 保存，并记录其字段路径。
- 非有限指标对应的像场不能产生有效最终 J。
- 复用原 GPU 已完成的 7 组复 OTF 和 14 组无效记录，**没有重新计算这些细网格 PSF**。
- 工作站复验成功：RF24 最终保持 `valid=False`、`J_task=null`，无效场为半场和边缘；NaN 位于边缘基线矩阵第 4、6 列。

证据：[rf24_gpu_report_recovered.json](https://github.com/wangteng1111/cots-LAMCTS/blob/workstation-results/remote/artifacts/000-000-qfilm04-recheck-20261029-01/rf24_gpu_report_recovered.json)。
本地相同报告恢复与严格 JSON 回归也通过；本地恢复仅重算暂定基线，不能标为 CPU 细网格 PSF 结果。
