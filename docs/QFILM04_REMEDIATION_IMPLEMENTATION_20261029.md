# Qfilm0.4 收敛改造：实现与验证记录

本轮将上一份[针对性方案](QFILM04_TARGETED_REMEDIATION_SPEC_20261029.md)的第一批核心改动落实到代码。默认 API/CLI 已切换到收敛检查路径；**不代表三个代表工况或全部 11 个处方已获得通过认证的 PSF/MTF**。训练资格仍为 false。

## 已实现

| 问题 | 本轮实现 |
|---|---|
| 固定 256² 瞳面欠采样 | 冻结网格候选 256/512/1024/2048/4096；整个探测窗口分块，对所有相邻有效源点计算未取模相位差的保守界；另做确定性中点光线抽查；相位通过后仍须实际积分加密比较 |
| 出射面随网格移动 | 从处方的曲面孔径包络构造镜后空气中的固定平面；无可证明的空气间隔或缺少孔径时明确拒绝 |
| 归一化掩盖截断 | 始终输出原始轴向强度投影、像素面积、窗口内强度积分、20 μm 边界带比例及峰值位置；积分明确为标量场积分，未解释为实测瓦特 |
| 不检查窗口/步距 | 支持 0.64/0.96/1.28 mm 扩窗、0.25→0.125 μm 复验及最终瞳面/窗口/步距联合提升；每次使用相位安全的网格 |
| FFT 频率插值与复相位 | 按真实像素中心直接计算目标频率的复数离散傅里叶和；保留色间平移相位，最后取模；当前径向像场沿 x，x=T、y=S |
| 高密度积分显存 | 对探测点与源节点同时分块；源块固定 65,536 节点，跨源块累加复场；按总源点×探测点预算拒绝超额计算 |
| Jacobian 绝对值掩盖折叠 | 先检查带符号映射和有效差分模板；允许整体负定向，拒绝同一连通区域内定向变化，包括奇异节点把正负区域隔开的情况 |
| 主光线受挡导致整场退出 | 有足够透射光束时使用固定的确定性光束参考位置；波长间真实坐标差仍保留；历史 J 所需主光线指标不被伪造 |
| 有效性与任务约束混合 | 单独记录几何、波前支持、四类收敛、20% 填充任务约束、历史目标可用性、独立参考与训练资格；数值未收敛时 J=null，MTF 缺失，不回退到旧 FFT 值 |
| CPU/GPU 配置与记录混用 | 一次在 CPU 构造冻结计划，两设备复用相同源哈希、坐标、出射面、网格和频率；设备执行 ID 分开记录，无 CUDA 时不隐式改用 CPU |
| 结果恢复与旧状态覆盖 | 每个场点/波长写原子检查点；验证器写不可变终态，禁止 running 覆盖已完成终态；大二维控制数组保留 .npy 与 SHA256 清单 |

默认相位目标 0.25 周期、瞳面/扩窗复 OTF 变化 0.002、窗口积分相对变化 0.005、步距复 OTF 变化 0.001、联合变化 0.005。均为工程验收目标，不是已获得的严格误差界。规划器检查的是离散源点对，并辅以有限中点抽查；连续瞳面仍需实际加密和独立参考验证。

## 本地验证

1. `validation/qfilm04_remediation_tests.py`：11 项测试，包括直接二维傅里叶和对照、两色已知平移、映射折叠、随机观察点相位界、原始积分与像素面积、计划身份、不可变终态、资源耗尽、禁止 CUDA 回退、实际积分序列的冻结重放及最终评分中禁止旧 FFT 值泄漏。
2. 新生产提取器的 8 项解析 Airy 控制：0.25 μm、0.64 mm 支持，最大 MTF 绝对差为 **0.000445～0.002089**。这是解析像面采样控制，不是实际镜头认证。
3. 正/斜入射中性平面、无损输入映射控制：1024² 网格的几何投影功率相对解析圆孔结果误差约 **0.3465%**；256² 时约 1.4141%。该检查没有验证一般内部光阑、镀膜或衍射能流闭合。
4. EF40/430、EF40/550、RF50/670 三个真实公开处方中心条件：新规划器重新审计 256²/512² 网格。在 0.64 mm 窗口上，512² 邻接相位**分块上界**约为 0.614、0.466、0.632 周期，均未达到 0.25 周期目标。此结果为风险筛选，不是实际 PSF/MTF 误差。
5. 边缘光束准备控制：RF35/550 nm 在 h=1 仍能准备波前，几何填充约 16.65%，单独标记历史填充约束失败；EF35/550 nm 在 h=1 的主光线受挡，但剩余有效光线可以定义固定参考。未据此宣称边缘 PSF 已收敛。

原始记录在 `artifacts/qfilm04_new_extractor_airy_20261029.json`、`artifacts/qfilm04_lossless_input_controls_20261029.json` 和本轮 remediation audit/controls 子目录。工作区由 API 同步时，本地 git HEAD 可能落后；审计另存实际执行源文件 SHA256，不能只凭本地 HEAD 认定执行版本。

## 已提供但未开放为经验证默认物理模型

- `input_ray_tube_lossless`：使用入射参考平面坐标映射、入射投影面积和出射方向构造 ray-tube 振幅。仅有限无损控制通过；默认仍保留明示的均匀光阑通量模型，避免把未经一般验证的能流模型当成事实。
- `rs1`：提供不同边界算子的标量传播选项，尚未完成真实处方上的独立收敛与出射面不变性验收。
- 光谱默认明确标记 `normalized_fixed_weights`。物理谱通量模式会返回 `SPECTRAL_TRANSPORT_UNVALIDATED`，不会用被截断窗口的能量推算光谱权重。实际胶片光谱响应、镀膜损耗和制造误差仍待数据与验收。
- 本轮没有部署或重启 Bridge 服务。远端旧的可变心跳仍可能滞后；应读取新任务的不可变终态和原始产物。中断后可重用已导出的冻结计划；自动从半完成积分中恢复还未实现，复验使用新任务 ID。

## 使用

默认完整候选（开销可能很高，达到资源上限会明确返回未完成收敛）：

```bash
python -m evaluator.qfilm04 -c --prescription lens.json --fields 3 --output cpu.json
python -m evaluator.qfilm04 -g --prescription lens.json --fields 3 --resolved-plans cpu.json.plans.json --output gpu.json
```

历史固定网格：加 `--legacy-fixed-grid`；或 API 显式 `convergence=None`。旧结果和新结果具有不同配置身份，不能混排成已验证镜头性能排名。

三个代表条件的完整复算验证器：

```bash
python validation/qfilm04_remediation_run.py --mode solve --case all --backends g c --save-full-psf
```

该验证器每个条件先生成相位候选计划；第一个设备完成自适应尝试后，将实际积分网格序列冻结，第二个设备按同一顺序完整重放，再独立检查收敛。若临界容差导致选择分歧，明确返回 `FROZEN_PLAN_DIVERGENCE`。只有双方全部数值收敛、实际设备不同、执行 ID 不同且所有对应网格结果一致时，才将 `full_condition_pair_verified` 置 true。8 μm 小块算术测试单独命名，不能充当全窗口 PSF 通过证据。

工作站首先运行新代码的算术与边缘控制，然后运行三个代表条件。全部 11×3×7 条件的认证复算应在这三个条件达标后展开，避免继续积累欠采样结果。
