# Qfilm0.4 针对性解决方案与实施规格

状态：**工程方案，尚未实现或通过验收**。本文件不修改现有物理求解器、不重算镜头结果、不改变既有标签资格。依据为 `b1ff1a9b1f6d72cd5b6c7cb61cbf09f25a127388` 及此前实际处方相位审计。

## 总体设计

先建立可收敛、可追溯的直接积分参考，再做加速。保留 0.25 μm 像面默认步距，改造以下数据流：

`处方与入射条件 → 带功率的光线束 → 真实出射面复场 → 相位/映射检查 → 自适应积分与窗口收敛 → 指定物理频率复OTF → 物理指标 → 任务约束与J`。

CPU/GPU 共用同一物理代码、float64 和冻结采样计划；执行设备与实际计算记录分别保存。以下数值门槛是初始工程目标，不是已有误差保证。

## A. 瞳面积分欠采样：相位检查 + 网格加密双重验收

### 改动位置

- `qfilm03_physical_huygens.py`：拆出 `prepare_wavefront_bundle` 和 `integrate_fixed_film`。
- 新增 `qfilm04_sampling.py`：生成和验收采样计划。
- `PhysicalHuygensConfig`：加入自适应策略、资源上限和收敛门槛。

### 具体算法

1. 每个像场、波长先生成候选瞳面网格，级别初始取 256/512/1024/2048。资源允许时可继续扩展；2048 不是统一认证上限。
2. 为同一处方预选真实镜后空气中的固定出射平面，跨波长和网格级别保持不变。其位置应由物理表面包络和可用空气间隔决定，避免每次用采样点的最大 z 值移动参考面。
3. 在相位取模前，对相邻有效瞳面节点计算：

   `Δc_ab(P) = [OPL_b - OPL_a + |P-Q_b| - |P-Q_a|] / λ`。

4. 在探测窗口中心、边缘和角点及内部粗网格检查。不能把四个或九个点自动视为整个窗口的证明。
5. 对位于同一出射平面的两个源节点，可用观察窗口分块的保守界减少漏检：若块中心为 P0、半对角线为 ρ，源节点距离为 d，传播轴向距离为 L，则

   `max_P |Δc_ab(P)| ≤ |Δc_ab(P0)| + min(2,d/L)*ρ/λ`。

   该界源于传播距离差的横向梯度界。它只约束**已采样邻接源点对**在观察块内的相位差，不保证连续瞳面内部无未解析结构。还要做瞳面单元中心/边中点抽查和后续实际积分加密。
6. 初始保守筛选目标为邻接相位变化不超过 0.25 周期；超过 0.5 周期必须触发警报。若全窗界过保守，细分观察块并重新评估，不直接放宽为“通过”。
7. 选出相位检查通过的网格后，再计算同一物理坐标下相邻两级网格的**复 OTF**。只有模值相近不够，因为色间相位会影响综合 MTF。
8. 初始目标 `max|H_N-H_2N|≤0.002`；同时检查综合 MTF。若不通过，继续加密；资源耗尽则输出 `PUPIL_UNCONVERGED`，保留诊断数据但不输出可认证标签。

### 为什么采用这个方案

实际相位审计中，EF40 蓝光、RF50 红光的 256² 瞳面在窗口外圈出现约 1.08 周期邻接步进，512² 仍局部超过半周期。固定提升到某一个分辨率不能替代自适应检查。

### 加速的后续位置

高密度直接积分是数值参考。再研究单元连续积分或高阶自适应求积，对快速载波解析处理，并与该参考比较。单纯更换 FFT/NUFFT 库、给旧离散求和加速、或仅重写参考相位，不足以证明原求积误差已消失。

## B. 窗口截断与归一化：保存原始量，做联合收敛

### 输出和存储

积分器同时返回：

- 原始强度 I、像素面积、强度积分约定及窗口内积分；
- 原始轴向投影 `sum_y I` 与 `sum_x I`；
- 窗口中心、波长、像场、出射平面及实际网格计划；
- 多个物理宽度边界带的能量比例、峰值位置和共同中心区域统计；
- 归一化 PSF/OTF，作为派生量。

跨步距比较的积分须含像素面积，不能比较裸 `sum(I)`。单色整体尺度可以在归一化 MTF 中抵消；跨波长通量比较前必须统一源功率、传播核波长因子和场强/能流约定。

始终保存两个轴向原始投影和元数据，便于低成本重新提取目标频率；对关键控制案例、异常案例和最终候选另存完整二维数组及校验和。完整数组可保留于持久工作站结果目录，Bridge 上传小型摘要和索引，不必把所有大数组塞进 Git 文本附件。

### 收敛流程

1. 保留 0.25 μm；窗口候选为 0.64/0.96/1.28 mm，必要时扩展。
2. 每次扩窗重新检验 A 项的相位采样，或一次为最大测试窗口选择足够的瞳面网格。
3. 固定机械像面、物理原点和源场尺度，比较相邻窗口的原始强度积分、共同区域和复 OTF。
4. 初始目标：积分相对变化≤0.5%，指定频率复 OTF 变化≤0.002；这不是严格的窗口外漏能上界。
5. 边界能量超过 1% 触发扩窗或人工复核，不能单凭低于 1% 宣布正确。
6. 对代表性条件做 0.25→0.125 μm 的像面步距交叉检查，保持相同支持和瞳面计划，初始复 OTF 变化目标≤0.001。
7. 最终将瞳面、窗口、步距同时提升一级，验证综合 MTF 最大变化≤0.005。单轴各自通过不等于耦合误差自动通过。

## C. 振幅与 Jacobian：从入射功率构造出射场

### 选择明确的能流约定

对均匀、准直入射光，保留瞄准光阑前的入射参考平面坐标。若参考平面为 z 常数、入射角为 α，则每个光阑单元代表的入射投影面积，需要包含输入坐标映射和 cosα。沿每条 ray tube 累计透射功率，而不是把每条光线默认成等功率。

实施接口建议：

`RayBundle = {stop_uv, input_xy, input_direction, exit_xyz, opl, exit_direction, input_area, transmitted_power, geometry_mask, rejection_reason}`。

出射场重建从 ray tube 功率、实际出射单元面积和方向投影推导。若采用物理场幅度标量 U，能流与 |U|² 的关系须明确包含所选平面法向及介质约定；不能把任意归一化的场强积分直接解释为瓦特。当前 `sqrt(J_exit)` 是特定均匀光阑通量假设下的积分权重，不是所有内部光阑模型的通用功率公式。

### Jacobian 与参考传播

- 保留有符号 Jacobian，先检查连通区域内符号变化和局部奇异性，再形成面积权重。正常坐标轴次序可能使整体符号为负，不能据此一律拒绝。
- 映射多值/折叠时返回 `EXIT_MAPPING_UNSUPPORTED` 或进入独立高风险复验，不用绝对值隐藏问题。
- 在相同真实出射复场上，增加按明确定义的 Rayleigh–Sommerfeld 边界算子实现的独立参考，统一波长常数与倾斜约定。
- 不把独立传播核当成瞳面欠采样的替代修正。两者都须先达到各自采样收敛。

### 验收控制

无透镜平面波（正入射、斜入射）、解析圆瞳、受控理想透镜、有内部光阑但无额外损耗的映射、有限孔径渐晕。另在可用镜后空气间隔中移动出射参考平面，验证同一固定像面的结果稳定。

初始目标：已声明能流模型下入口/出口功率闭合≤0.5%；不同参考面得到的目标复 OTF 变化≤0.002。该阶段先取透射系数 T=1 可作为明确的无损控制；镀膜与实际材料损耗另行加入，不能靠调损耗拟合伪峰。

## D. 多波长：区分两种明确的模型

### 模型一：历史固定权重

保留现有七波长权重，用于历史复现。输出显式标记 `spectral_model=normalized_fixed_weights`，不得称为某种实际胶片的完整响应。

### 模型二：物理通量权重

以入射谱、透射能流与探测响应为定义，先合成实际强度，再统一归一化：

`I_poly(x,y) = sum_lambda S(lambda)*R(lambda)*I_unit_input_lambda(x,y)`。

其中单色 I 已按相同单位入射功率及传播算子定义，包含透射与渐晕。所有颜色使用相同固定像面坐标。采用光子计数响应时须明确能量到光子的转换，不能与能量响应权重混用。

不从有限窗口内截断能量推导或调整光谱权重；透射功率应来自已验收的能流模型。缺少实际光谱/响应数据时，保留理想模型并标注假设。

验收：单色极限、两色已知位移、已知透射比；实空间强度叠加与复 OTF 叠加得到的 MTF 应一致，初始差异目标≤1e-4。

## E. MTF：指定物理频率的直接复 OTF

位置：替换或扩展 `coherent_otf_axis`。

1. 从原始 PSF 或保存的轴向投影，直接计算请求频率的离散傅里叶和。
2. 坐标使用真实像素中心 `(j-(n-1)/2)*pitch`，不由数组索引隐含原点。
3. 保留 Hx、Hy 的复数；按实际像场方向映射到 T/S。
4. 色间位移保留傅里叶平移相位，合成后才取绝对值。
5. 当前 FFT 线性插值路径暂留作交叉检查，不作为新参考。

这样移除频率插值环节，并避免为两条频率轴计算完整二维 FFT，但它不会修复错误 PSF。

验收：Airy、非对称正强度分布的指定平移、单色/两色组合。与同一离散 PSF 的直接二维傅里叶和比较，初始绝对复 OTF 差≤1e-10；这是离散提取器的数学检查，不是物理误差指标。

## F. 主光线、渐晕和最终 J：物理有效性与任务约束分层

### 主光线被挡但仍有透射波场

保留 `reference_ray_blocked=True`，用有效 ray tube 功率加权的确定性光束参考定位窗口。窗口原点在同一场点的网格加密过程中冻结。优先使用绿色参考，其他波长保留真实位移；不能把每种颜色独立居中后消除色差。

如果有效波场不足或映射不支持，明确返回原因；不以任意位置或随机光线估计掩盖失败。

### 任务约束与评分

保留现有 20% 几何瞳面填充门槛作为可复现的历史任务约束。它与真实相对照度不是同一个量；采用物理通量约束时必须给新的目标定义版本，不能与旧 J 混排。

建议状态字段：

`geometry_valid, wavefront_supported, pupil_converged, support_converged, pitch_converged, reference_validated, constraints_passed, label_valid, empirically_calibrated`。

- 数值未收敛或模型不支持：`label_valid=False`，不当作低质量负样本。
- 物理指标可信但不满足设计约束：保留可信指标和约束违例，可用于将来的约束学习负样本；这不等同于计算失败。
- 约束失败的 J 可按预先声明的罚函数定义，或保持 `J_task=null` 和明确原因；不可静默给零值或任意极差值。
- 新物理指标与历史代理量分开存储，目标函数版本参与缓存和排序。

当前 `training_eligible=False` 保留。只有标签所声明的物理模型、数值收敛、来源和独立参考等门槛满足后，才重新评估资格；实物标定另有独立状态。

## G. 配置、缓存与恢复

CPU/GPU 使用同一份冻结的 `resolved_sampling_plan`，包含每个场点/波长的实际瞳面密度、窗口、原点与出射参考面，避免两设备独立自适应选到不同网格后误报差异。

`physics_hash` 包括处方、源场/光谱约定、映射与传播模型、实际网格、窗口、像素、原点和指标版本。
`execution_id` 另包括设备、软件版本及执行记录。共享物理哈希不能让 CPU 缓存冒充已执行的 GPU 测试。

每个场点/波长独立持久化投影、诊断与校验和。失败复验使用新任务 ID，记录父任务和复用数据来源。监控按递增序号或更新时间拒绝旧心跳覆盖新记录；已完成状态使用不可变终态快照。

## 实施批次与交付物

### 第一批：先把三项代表条件变成可收敛参考

- EF40/430 nm 中心像场：蓝光边界异常。
- EF40/550 nm 中心像场：绿色控制。
- RF50/670 nm 中心像场：红光边界异常。

先做 A、B、E、G。对通过相位初筛的相邻精度级别计算完整 PSF/OTF，记录加密结果。只返回有限数值不算通过。
交付：采样计划、未归一化投影、复 OTF、边界与能量诊断、收敛报告。

### 第二批：通量模型和边缘有效性

实施 C、D、F 的控制。用 RF35 边缘检验低通量但仍可传播的情形，用 EF35 检验主光线受挡但部分光束透射，用 RF16/RF24 检验无透射场和源处方覆盖范围。
交付：能流约定、传播参考对照、原因分层的有效性输出。

### 第三批：恢复完整 11 处方验收

两设备按同一采样计划完成原三场点、七波长任务。目标复 OTF CPU/GPU 差先设≤1e-6，并检查积分与实际执行记录。
数值通过后再扩展像场密度与实际 COTS 候选；独立传播比较目标 MTF 差≤0.01，候选排序需在更高精度下稳定。相近候选保留不确定性，不强行指定赢家。
