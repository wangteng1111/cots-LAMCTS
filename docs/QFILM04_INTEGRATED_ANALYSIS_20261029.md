# Qfilm0.4 已有结果的综合分析

分析范围：此前已汇总的 8 个公开处方、133 张 GPU 单色 PSF，以及几何/OPD、Airy 和 CPU/GPU 控制。本文不是新的工作站实时状态快照，也没有新增真实镜头 GPU 收敛实验。

**判断：Qfilm0.4 已有较好的几何、光程与设备算术一致性证据，但真实摄影处方的波动积分和最终评分尚未通过数值收敛验收。当前最值得优先验证的是瞳面积分欠采样，而不能只把问题解释为像面像素不够细。**

## 已建立的可信部分

1. 真实处方共同有效光线审计中，90 组已完成条件的最大像面 OPD 跨实现差约 3.24×10⁻⁸ μm。这支持已采样光线的折射和光程实现一致，不是绝对物理误差或制造公差的上界。
2. 0.25 μm 的 8 组解析 Airy 控制中，最大绝对 MTF 偏差约 0.000445–0.002089，明显改善原 5 μm 点采样的混叠。它隔离的是像面采样，并未检验实际出瞳积分。
3. EF40 处方、550 nm 中心场的小区域 CPU/GPU PSF 最大绝对差约 3.16×10⁻¹⁴。该控制只覆盖 16² 像素、4×4 μm，不能推广为完整窗口或完整 J 的误差。
4. RF24 NaN 严格 JSON 保存故障已通过本地与工作站恢复复验。已完成 PSF 不再因无效几何指标的 NaN 而丢失；无效场点保持无效。

这些测试共享部分几何方程、输入场与采样定义，对共享的物理近似和采样错误并不敏感。数值一致性、数值收敛、物理正确性和实物预测误差必须分别验收。

## 边界能量异常是广泛存在的采样警报

对全部 133 张已完成单色 PSF 重新统计。外圈为 0.64 mm 正方形窗口最外 20 μm 的边界带。

| 统计量 | 结果 |
|---|---:|
| 边界能量中位数 | 6.96% |
| 边界能量 P95 | 59.96% |
| 最大值 | 85.05% |
| 超过 1% 诊断线 | 95/133，71.4% |
| 超过 10% | 57/133，42.9% |
| 超过 50% | 13/133，9.8% |

1% 是诊断触发线，不是实物误差界。边界带只占窗口面积的 12.109%，但在部分结果中包含大半归一化能量，说明必须检验窗口边界附近的波场结构。
85.05% 是窗口**内部外圈**的能量比例，不是窗口外损失、实物镜头误差或 MTF 误差。
每张 PSF 已被窗口内总和归一化为 1；因此 `PSF.sum()=1` 不能证明物理能量守恒或支持窗口足够。

每个波长对应相同的 19 个已完成处方/场点组合，波长间可作匹配的诊断比较：

| 波长 / nm | 边界能量中位数 | 最大值 |
|---:|---:|---:|
| 430 | 4.59% | 59.01% |
| 470 | 1.57% | 37.03% |
| 510 | 1.56% | 39.31% |
| 550 | 2.50% | 33.63% |
| 590 | 11.17% | 60.64% |
| 630 | 27.90% | 76.58% |
| 670 | 38.22% | 85.05% |

红区异常仍有明显统计表现，但 EF40 的最坏情况是 430 nm。因此不能给所有镜头统一加入一个“红光修正系数”。

## 新线索：离散瞳面可能产生 PSF 复制像

Huygens 积分有三个独立数值尺度：瞳面采样、像面步距、像面支持宽度。当前配置是 256² 瞳面、2560² 像面、0.25 μm 步距、640 μm 宽窗口。像面变细并不会自动补足瞳面信息。

在理想近轴均匀圆瞳的 Fraunhofer 控制中，若瞳面直径 D、单边 N 点、间距 Δu≈D/N，则离散复场的强度具有周期：

`L_repeat = λ f / Δu ≈ λ F/# N`。

这是有限均匀瞳面积分的周期性，不要求算法使用 FFT。真实 Qfilm 出射平面坐标并不均匀，且包含像差和几何非线性，所以这里的公式只作诊断估计，不能当作真实镜头的精确周期。

使用实际来源处方的近轴 F/# 估计，得到两项值得检验的对应：

| 案例 | 估计复制距离 | 当前边界带位置 | 已观察到的该组外圈能量 |
|---|---:|---:|---:|
| EF40，430 nm，F/2.809，N=256，中心场 | 309.22 μm | 300–320 μm | 59.01% |
| RF50，670 nm，F/1.842，N=256，中心场 | 315.87 μm | 300–320 μm | 85.05% |

**已实际运行的理想圆瞳控制**表明：在这些 N=256 复制位置，解析 Airy 相对峰值强度约为 2.445×10⁻⁹，而离散圆瞳积分产生相对强度 1 的伪峰。N=1024 在这些特定位置约为 2.312×10⁻⁹。N=512 在同一位置可出现偶然抵消，这也提醒我们不能只用单点值判断收敛。

因此，瞳面欠采样是一个已在控制实验中复现、且与部分真实处方异常位置吻合的机制；**真实处方的因果归因仍待 N=256/512/1024 等实际积分对照确认**。它不能单独解释所有案例。若该机制占主导，盲目扩大窗口可能纳入更多伪复制峰，而不是改善结果。

还有一个应单独核对的数值环节：固定窗口 W=0.64 mm 时，FFT 的频率间距仍为 1/W=1.5625 lp/mm。把像素从 5 μm 改为 0.25 μm 提高了像面 Nyquist 上限，但不会改变这个频率间距。当前生产路径对复 OTF 做 FFT 频率插值，而既有 Airy 控制直接在指定频率求傅里叶值；二者覆盖的误差环节并不完全相同。可对相同 PSF 的轴向投影直接计算所需物理频率的复 OTF，交叉检查插值与坐标相位约定，不能先假定其误差已经可以忽略。

## 无效场点必须拆分原因

| 现象 | 目前可以解释为 | 不能直接解释为 |
|---|---|---|
| EF35 边缘仍有透射光线，但主光线无效 | 当前窗口定位和有效性策略拒绝该场点 | 实物镜头无法在边缘成像 |
| RF16/RF24 最外场无可用透射光线 | 当前处方/场角/口径/导入模型不传光 | 对应量产商品必然不覆盖全画幅 |
| RF35 边缘完成全部 7 张物理 PSF，但没有最终 J | 工程评分门槛拒绝该场点 | 波动传播未运行或没有透射波场 |
| RF24 NaN 导致 JSON 写失败 | 报告持久化错误 | 已完成中心 PSF 的光学求解失败 |

RF35 的具体数据：边缘加权瞳面填充约 **16.64%**；7 个波长均完成传播，每色约 8,556–8,576 条有效积分光线。代码要求每色填充率均大于 **20%**，因此评分无效。这里是明确定义的工程拒绝门槛，不能视为无成像的物理定理。

主光线被遮挡时，其他透射光线仍可形成波场。可研究使用确定性的有效光束质心定位窗口，但必须保留实际像面位移、统一物理坐标和窗口收敛，不能把重新定位当作重新调焦或消除真实渐晕。

## 当前 J 反映什么

实际评分代码使用 MTF 细节损失、横向色差主光线跨度惩罚、照度代理和畸变惩罚。当前 J 没有直接使用绿色 EE 或 Strehl 列；照度仍包含瞳面填充与 cos⁴ 的代理近似。

`J_task = 0.75 J_area + 0.25 J_tail`，其中尾部项为最差 10% 面积的损失。仅三个径向场点，对真实最差区域仍是粗采样。

以下占比仅针对 **J_area**，不是 J_task 的贡献占比：

| 处方 | 暂定 J_task | MTF 损失占 J_area | 横向色差项占 J_area |
|---|---:|---:|---:|
| EF40 | 0.665772 | 67.4% | 24.4% |
| EF50 | 2.525160 | 39.4% | 56.6% |
| RF50 | 0.955248 | 78.7% | 16.8% |
| Yongnuo 50 | 0.963345 | 93.3% | 3.6% |

因此 EF50 的高分不能只归因为分辨率差；其面积平均损失中，色差位移惩罚占比超过一半。不同案例的 J 还受焦距、光圈、源处方和固定像面条件影响，不能直接作为商品品牌排名。
RF50 与 Yongnuo 的暂定 J 仅差 0.00810，但尚无采样不确定度或排序稳定性证据，不能据此确认优劣。

## 对 Alpha Lense / COTS 搜索的影响

- 这些结果适合光学回归、异常分类与求解器改进，不适合作为正式高精度物理真值标签。
- 优化器可能偏好有采样伪峰的候选；较大的搜索量不能消除目标函数的系统误差。
- 不能把“数值未收敛”“主光线定位失败”“透射率低于工程门槛”统一编码成低光学质量。应分别保存几何有效性、数值收敛状态、任务门槛及物理认证状态。
- 未回传的三个 GPU 案例与完整 CPU 结果仍属于缺失证据，不能加入成功率、误差或完整加速比统计。
- 应在相同 COTS 任务、相同约束下检验候选排序。商品关联专利处方间的暂定 J 大小不能替代 COTS Top-K 稳定性验收。

## 优先验证顺序

1. **瞳面收敛与伪复制诊断**：优先选 EF40/430 nm 中心、RF50/670 nm 中心及 EF40/550 nm 中心控制；固定像面与窗口，比较 N=256/512/1024，必要时更高，检查中心 PSF、外圈结构和固定频率 MTF。真实积分尚未执行这项新验证。
2. **联合窗口收敛**：先保证所测最大窗口的积分采样足够，再比较 0.64/0.96/1.28 mm；保留 0.25 μm，记录未归一化强度积分和共同中心区域变化，不仅比较各自归一化后的 PSF。
3. **处方和评分审计**：核对源文件指定物距、像面、光圈、有效视场；分离 20% 工程门槛与物理传播有效性。焦面扫描可用来诊断源处方焦点，不能偷偷改写固定像面任务。
4. **独立物理与排序验收**：对经上述收敛的真实处方，采用独立且自身收敛的传播方法复核，再在真实 COTS 候选上比较 Top-K 排序稳定性。

原先提出的 MTF 自收敛≤0.005、独立方法差≤0.01仍只能作为待达到的工程目标。候选之间若小于数值变化幅度，应保留排序不确定性，而不是强行指定赢家。
