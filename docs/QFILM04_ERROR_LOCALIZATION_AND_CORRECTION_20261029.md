# Qfilm0.4：当前计算问题的定位与纠正方案

本次核对的 main 为 `6371129ce4c1f5796f8ea46331996c1e081149ea`。物理积分文件本地内容与该提交的 GitHub blob 一致。新增工作是实际处方的积分相位采样审计；没有修改物理求解器，也没有重算完整 PSF 或认证新的 MTF 精度。

**首要问题：当前 256² 瞳面网格不能可靠覆盖 0.64 mm 大像面窗口中所有目标点的振荡积分。0.25 μm 像面步距没有解决这项瞳面积分问题。其次，有限窗口归一化、真实通量与振幅映射、MTF 提取及有效性/评分门槛仍需分别修正或验收。**

## 1. 新证据：实际处方的边缘积分相位采样风险已观察到

使用当前 `trace_pupil`、真实出射平面、相同 OPL 和 Jacobian 有效节点，在 CPU float64 上检查实际 Huygens 被积函数：

`phase_cycles(u,v; x,y) = [OPL_exit(u,v) + R(u,v; x,y) - constant] / lambda`。

必须检查取模前的相位；`remainder(...,1)` 之后的相邻差不能用于此诊断，否则整数周期被隐藏。
下表是轴向相邻有效瞳面节点的最大绝对相位步进，单位为周期。窗口半宽 320 μm，310 μm 点处于现有外圈中。

| 实际处方与波长 | 256²，窗口中心 | 256²，距中心 310 μm | 512²，距中心 310 μm |
|---|---:|---:|---:|
| EF40，430 nm | 0.0812 | 1.0763 | 0.5381 |
| EF40，550 nm | 0.0385 | 0.8090 | 0.4047 |
| RF50，670 nm | 0.0739 | 1.0797 | 0.5414 |

在 (310,310) μm 点，256² 最大步进分别为 1.0780、0.8151、1.0823 周期。EF40 蓝光和 RF50 红光升至 512² 后，部分邻接步进仍超过半周期。

这表明窗口中心局部求积相对平缓，并不代表整张大窗口都得到足够的瞳面采样；中心的 CPU/GPU 16² 小区域一致性测试无法检出这种窗口边缘问题。
半周期是振荡积分采样的诊断准则，不是通用的严格误差界。即使通过这一检查，也仍须实际 PSF/MTF 网格加密收敛。此审计没有测量完整 MTF 误差，也没有证明全部异常只有一个原因。

### 应怎样改

位置：`evaluator/qfilm03_physical_huygens.py::eval_fixed_film`；验收配置位于 `qfilm03_physical_mode.py::PhysicalHuygensConfig.validate`。

- 增加取模前相位采样检查，覆盖窗口中心、轴向边缘、角点及需要时的内部自适应点；使用相邻有效节点，避免跨无效孔径边界差分。
- 根据波长、像场、实际出射面映射、像差和目标窗口自适应选择瞳面密度，而不是仅检查 `pupil_n >= 256`。
- 可将相位步进小于半周期作为最低警报门槛，另设更保守的裕量；这些是初筛，不替代 ΔMTF 收敛。
- 对这几个问题条件，以 1024² 等更高密度建立完整积分参考；如仍未收敛则继续加密。不能把固定 512² 或 1024² 宣布为所有镜头的统一认证值。
- 达到资源上限后应返回“未收敛”，而非仅因返回有限数值就给有效物理标签。
- 高密度直接积分建立参考后，再研究单元连续积分、对快速载波的解析处理或高阶自适应求积；仅给旧离散和加速、或仅做参考相位分解，不会自动消除求积欠采样。

先前理想圆瞳控制与真实异常位置的吻合，现在多了一项实际处方的相位诊断支持；完整误差归因仍需真实 PSF 网格收敛结果。

## 2. 有限窗口归一化掩盖支持不足和积分伪峰

当前 `eval_fixed_film` 在每个单色窗口上计算强度后，立即除以窗口内总和，输出总和恒为 1。
这对单色 MTF 的尺度归一化本身是合法的，但它没有证明支持窗口足够，也没有保留验证绝对/相对通量所需的信息。

此前 133 张 PSF 的外圈能量中位数 6.96%，95 张超过 1% 诊断线。外圈异常可能包含真实宽 PSF、截断、采样复制像或其组合。

### 应怎样改

- 同时保存未归一化强度、像素面积因子、源场/传播核归一化约定及窗口内积分。
- 积分能量应考虑 `sum(intensity)*pixel_pitch_mm**2`；跨步距比较不能只比较像素强度的裸总和。
- 固定像面及足够的瞳面采样后，比较 0.64/0.96/1.28 mm 支持窗口。扩大窗口可能提高所需瞳面密度，因此必须联合验收。
- 比较共同物理区域的强度变化与固定物理频率 MTF，而不只比较各自归一化后的数组。
- 当前积分省略的单色整体尺度因子对归一化形状可抵消，但在跨波长或跨口径绝对通量比较前，必须明确波长及源功率的归一化约定。

## 3. 出射振幅与光通量映射仍是物理模型的缺口

位置：`qfilm02_huygens.py::exit_area_weights` 与 `eval_fixed_film` 的振幅、倾斜因子部分。

当前 `sqrt(J_exit)*dA_stop` 积分权重，依据的是每单位光阑面积具有恒定入射通量的假设。实际光线是从均匀入射平面反求、瞄准光阑网格；内部光阑前的光学映射可能改变每个光阑单元代表的入射能流。
因此只有出射 Jacobian 仍不足以认证入射到出射的通量输运。轨迹、OPD 或双方 Jacobian 数值一致，也不能证明双方使用的振幅假设正确。

当前代码还先取 `abs(det J)`，再仅检查很小或非有限值；这没有显式验证连通有效区域内映射方向是否翻转。坐标轴约定可使整个正常 Jacobian 为负，所以不能简单把所有负号视为错误。

### 应怎样改

- 追迹时保留入射采样坐标和每个 ray tube 的物理功率，核对入射平面到光阑、再到出射平面的面积与投影因子。
- 从实际通量构造出射场振幅及面积积分权重，而不是仅用有效光线条数代替通量。
- 在取绝对面积前保留有符号 Jacobian，检查有效连通区域内的符号变化和局部奇异性；复杂映射必须单独复验。
- 明确所选标量积分形式及相应的倾斜/法向导数近似，使用独立控制检验，而不是在不同近似间混用因子。
- 在镜后可用空气间隔内选择多个真实传播平面，重建波场并传播到同一固定像面，检验结果对参考平面位置的稳定性。

这些是已确认的模型假设和未覆盖验收，不是此次已测得的全部 MTF 误差来源。

## 4. 多波长结果需要区分固定权重模型与真实宽谱成像

当前每色 PSF 先独立归一化，再使用固定七波长权重叠加复 OTF。这是一种数学上明确的固定后端光谱权重模型，但没有自动包含各镜头、像场、波长的真实透射光通量、镀膜或胶片/探测器响应。

### 应怎样改

- 保留当前固定权重模型用于历史复现，并明确其光谱权重含义。
- 另行定义真实光通量模型：入射光谱、探测响应、透射通量和统一物理坐标；对各色强度进行非相干合成，再统一归一化。
- 透射通量来自能流计算，不能直接以有效光线数充当。
- 不能用随窗口变化的截断能量偷偷调整光谱权重；先完成支持窗口与能量约定验收。

## 5. MTF 提取应改为指定物理频率的直接复 OTF

位置：`qfilm03_physical_huygens.py::coherent_otf_axis`。

当前对二维 FFT 的复数切片做线性插值。窗口仍为 0.64 mm 时，FFT 频率间距为 1.5625 lp/mm，像面步距变细不会改变它。已有 Airy 控制直接求指定频率傅里叶值，与生产提取路径覆盖的误差环节不同。

建议对同一离散 PSF 的轴向投影直接计算：

`H_x(f) = sum_j [sum_i PSF(i,j)] exp(-i*2*pi*f*x_j) / sum_ij PSF(i,j)`。

Y 方向同理。使用真实物理像素坐标，可在 5–80 lp/mm 等请求频率直接得到复 OTF；多波长合成仍保留色间位移相位，最后才取模。
这可消除频率插值这一数值环节，也避免为仅需两条轴线而计算完整二维 FFT；但不会修复已经有误的 PSF。
应以解析 Airy、已知平移的非对称 PSF、以及同一 PSF 的现有 FFT 提取进行交叉检查。

## 6. 有效性与 J 必须分层

位置：`qfilm02.py` 的 `obs[:,30]` 与 `score_image`，以及物理后端继承基线矩阵的部分。

- RF35 边缘已完成全部七波长传播，但加权瞳面填充仅约 16.64%，低于评分层每色大于 20% 的门槛。这是工程任务约束，不能称为无可成像波场。
- 主光线被遮挡时，其他有效光线仍可能形成波场。可用确定性的有效光束参考定位窗口，同时保留真实位移和光谱合成坐标；不能把定位失败等同于所有透射光线失败。
- 当前 J 混合了物理 Huygens MTF 与暂定的色差、照度代理和畸变规则，不等于完整摄影物理质量。对 EF50，J_area 中 56.6% 来自横向色差项。

纠正方法：分别输出 ray trace 有效性、波场可计算性、采样收敛、任务约束满足、评分定义版本和物理认证。20% 门槛如有任务依据可以保留在约束层，不应无说明地删除，也不应与数值失败混成一个标记。
J 只有在其输入分项达到对应有效/收敛条件后，才可进入候选排序或训练；未收敛结果应作为缺失标签或不确定结果保存。

## 建议执行顺序与验收

| 优先级 | 工作 | 验收依据 |
|---|---|---|
| P0 | 实际积分相位检查与自适应瞳面密度 | 相位风险下降，并完成实际 PSF/MTF 加密收敛 |
| P0 | 原始强度、通量约定与窗口联合收敛 | 共同物理区域与目标频率稳定，不依赖窗口内强制归一化掩盖差异 |
| P1 | 直接物理频率复 OTF | 解析、平移和现有提取的交叉检查通过 |
| P1 | 通量 Jacobian、倾斜项和多色权重 | 能量与传播平面稳定性控制、独立方法一致性 |
| P1 | 分离物理有效性、任务门槛与最终 J | 每次拒绝可归因；无效/未收敛结果不进入正式标签 |
| P2 | 独立传播与 COTS Top-K 稳定性 | 两套方法各自收敛后复核，候选差异大于数值不确定度 |

MTF 相邻精度级别变化≤0.005、独立方法差≤0.01仍是待达到的目标，不能视作当前已认证误差。CPU/GPU 完整验证应补齐，但更换执行设备本身不会消除共用网格的混叠。
