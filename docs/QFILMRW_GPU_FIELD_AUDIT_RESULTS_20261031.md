# QfilmRW：GPU 单线路与 11 处方视场校核（2026-10-31）

已完成 GPU 单线路切换和 11 个同源处方的视场审计。工作站双 RTX 5090 实测：33 个原生视场完成坐标标定，231 个“视场 × 波长”组合均找到有效透射样本；20 项回归全部通过，33 个生产入口边界场检查全部通过。最终验证结束于北京时间 2026-10-31T12:06:43.120439+08:00。

这次验收覆盖执行策略、视场坐标、光线可达性及有限复振幅边界场。没有重新运行新版完整 PSF/OTF 收敛矩阵，也没有完成全面光学模型或实测镜头验收；model_scope_validated 仍为 false，J_task 仍为空。

**已实施的修改**

- 公共 API、求解器、CLI 和矩阵调度只接受 CUDA；CPU 求解与 CPU 全矩阵参考线路停用，无 CPU 回退。旧 CPU 结果保留为历史证据，现行收集器不再以 CPU/GPU 一致性作为准入条件。
- 矩阵只调度 cuda:0、cuda:1。数值收敛、直接参考、原始 PSF 校验和与光学模型门槛继续保留。主机仍承担调度、文件/元数据检查及现有几何预处理；这不表示所有 Python/预处理都变为 CUDA 内核。
- 瞄准迭代忽略临时孔径裁剪，使用前组近轴矩阵初始化、最终交点残差和真正的逐面孔径检查；旧算法会把中间猜测的孔径失败永久累积到有效性掩码。
- 离轴调用必须提供明确物方角度；11 案例驱动默认使用 validation/fixtures/qfilmrw_audited_fields_20261031.json，并检查处方身份、源元数据、目标像高及标定残差。
- 主光线未求出时记录 reference_ray_unresolved，并注明实际使用透射样本质心定位；不再误称为已证实遮挡。CUDA 启动器建立可写的内核缓存目录，最终回归中原有缓存目录警告已消失。

**视场定义及核验方法**

旧测试使用 θ = atan(h × 21.63330765 / EFL)，其中 21.63330765 mm 是 36×24 mm 半对角线。这仅是近轴换算，畸变后实际像高可能显著不同。

本次原生测试的目标像高为 0、0.5×源 r_sensor、源 r_sensor；用 550 nm、忽略孔径的几何主光线反求物方半视角，并将同一角度固定用于 430、470、510、550、590、630、670 nm。物理孔径和七波长透射另行核验。最大坐标残差为 0.078175 µm，低于声明的 1 µm 门槛。

全画幅角点 21.63330765 mm 单独保留，不把较小的原生视场当作全画幅合格。源 r_sensor 是处方声明范围，不能仅凭元数据认定实际像圈已经验收；商品名也不等于工厂完整设计或实测规格。

**三个具体问题及纠正结果**

1. RF24：旧 41.2055° 所对应主光线像高仅 19.3478 mm，而真正全画幅角点需要 45.0728°。在旧角度、64×64 网格下，旧瞄准为 0，修正瞄准得到 990 条透射光线，独立首表面采样得到 210 条。真正全画幅角点在 550 nm、256×256 下也得到 4,988 条合法透射光线。原生边缘七波长均有光，但光阑网格成功透射占比仅约 10%，且存在未完成瞄准的节点，不能把它解释为完整瞳面已验收或真实能量透过率。主要孔径损失集中在面索引 7、9、11 等，完整逐面记录保存在原始审计终态。

RF24 源 focal_length 元数据为 39.5385 mm，独立 GPU 近轴重算为 24.70675 mm，并与冻结导入值一致。因此不应按这条源元数据或商品名修缩光学处方。本次保持源几何、玻璃和哈希不变，以实际追迹的角度—像高关系约束测试。

2. RF16：源 r_sensor=18.2 mm，源文件明确写明该专利不能覆盖全画幅。旧 52.7233° 工况的零光线也不成立：修正瞄准得到 502 条，独立入射采样得到 96 条（64×64、550 nm）。初次主光线标定失败，后用首表面 257 节点括根及 19 次二分，找到 52.9447469° 对应 18.1999218 mm；坐标残差约 0.0782 µm，光阑中心残差约 7.42e-8 mm。原生边缘七波长均有透射。

RF16 的生产瞄准器仍未恢复该主光线，而独立搜索确认 550 nm 物理主光线存在。因此当前主光线失败属于求解路径问题，不能写作真实遮挡。生产边界场暂以透射样本质心定位，并显式记录未解决状态。独立连续分支搜索最大已标定像高约 18.8746 mm；该数值只是此次有界搜索结果，不能当作镜头绝对覆盖上限。21.6333 mm 全画幅角点保留未标定，不缩小目标伪造通过。

3. EF35：旧近轴边缘角度 31.3706° 对应约 21.2334 mm，原生边缘应为 31.8116°。同一旧角度、64×64 网格下，旧算法只留 142 条光线，修正后为 1,094 条；轴上也从 2,920 恢复到 3,228 条。修正掩码/初始化/最终交点判据后，有效光线显著增加，同时真实孔径裁剪仍存在。

其余处方的独立 GPU 550 nm EFL 与冻结导入值均一致，最大相对差约 2.88e-16。这排除了当前导入焦距数值整体漂移这一解释，并不验证所有材料、面形或完整成像模型。
